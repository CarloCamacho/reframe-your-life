  <action>
Create `src/components/Tree/TreeNode.jsx` — a custom React Flow node component.

Import `Handle` and `Position` from `@xyflow/react`.

The component receives `{ data, selected }` props where:
- `data.rung`: 1 | 2 | 3
- `data.status`: 'active' | 'selected' | 'dormant'
- `data.label`: string

**Rung styling (Tailwind classes using theme tokens from Plan 03):**
- Rung 1 (root): `border-rung-root` border, `text-text-primary`
- Rung 2 selected/active: `border-rung-2-active bg-rung-2-active/10 text-rung-2-active`
- Rung 2 dormant: `border-rung-2-dormant text-text-muted opacity-50`
- Rung 3: `border-rung-3 bg-rung-3/10 text-rung-3`

**Base styling:** `rounded-xl border-2 px-3 py-2 text-sm font-medium max-w-[180px] text-center bg-surface-raised cursor-pointer transition-all`

**Selected state:** Add `ring-2 ring-white/40` when `selected` is true.

**Handle positions (CRITICAL for bottom-to-top tree):**
- Root node (rung === 1): source handle at `Position.Top` only (no target — it's the root)
- Rung 2 nodes: target at `Position.Bottom`, source at `Position.Top`
- Rung 3 nodes (leaves): target at `Position.Bottom` only (no source — they're leaves)

**Continue button:** If `data.rung === 2` and `data.status === 'active'`, render a small button below the label: "Continue" styled as `mt-2 text-xs px-2 py-0.5 rounded bg-rung-2-active text-white`. onClick logs "Continue clicked" to console (stub for TREE-07).

**Node click:** The component itself does NOT handle onClick — React Flow's `onNodeClick` on the `<ReactFlow>` component handles this (see Task 2).

Do NOT define nodeTypes inside this file. Export only the component as default.
