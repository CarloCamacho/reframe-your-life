  <action>
1. Create `src/hooks/useAuth.js`:
   - Import `signInAnonymously` and `onAuthStateChanged` from `firebase/auth`
   - Import `auth` from `../services/firebase.js`
   - Import `useAppStore` from `../store/appStore.js`
   - Export a `useAuth` function that:
     - Reads `setUid` from the store
     - Maintains local `loading` state (useState, default `true`)
     - In a `useEffect` (runs once on mount):
       - Call `signInAnonymously(auth)` (fire-and-forget — onAuthStateChanged handles the result)
       - Set up `onAuthStateChanged(auth, (user) => { ... })`:
         - If `user` exists: call `setUid(user.uid)`, set `loading` to `false`
         - If `user` is null: call `signInAnonymously(auth)` (re-trigger if signed out)
       - Return the unsubscribe function from onAuthStateChanged for cleanup
     - Returns `{ uid: useAppStore((s) => s.uid), loading }`
   - Do NOT use an AuthProvider/Context — the hook reads from Zustand directly

2. Extend `src/store/appStore.js`:
   - Add `uid: null` to initial state
   - Add `setUid: (uid) => set({ uid })` action
   - Keep all existing state and actions unchanged: `currentView`, `activeTreeId`, `setView`, `setActiveTree`, `goHome`
  </action>

|-----------|----------|-----------|-------------|-----------------|

| T-02-03 | Denial of Service | signInAnonymously called repeatedly | mitigate | onAuthStateChanged listener prevents repeated calls — only re-triggers signInAnonymously if user is null (signed out), not on every render |
